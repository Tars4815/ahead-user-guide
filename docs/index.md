# AHEAD User Manual

This manual explains how to navigate the AHEAD platform and how to enter, assess and consult data on events, assets, damage and losses.

## What you can do in AHEAD

The platform is organised into six sections, all reached from the [sidebar](getting-started/navigation.md):

| Section | What it is for |
| :--- | :--- |
| [Dashboard](getting-started/dashboard.md) | Overview of the data collected, with a map of reported damage locations. |
| [Events](data-entry/events.md) | Register and manage the events that cause damage, such as storms, floods or earthquakes. |
| [Owner Profiles](data-entry/owner-profiles.md) | Register the individuals or organisations that own or manage the assets. |
| [Baseline Information](data-entry/baseline/index.md) | Describe the assets and their elements before any damage, that is, their exposure characteristics. |
| [Damage & Loss Assessment](assessment/index.md) | Record and classify the damage and losses suffered by registered assets during an event. |
| [Queries & Reporting](analysis/index.md) | Retrieve, filter and analyse the stored information through queries and dashboards. |

## Order of work

The sections depend on each other. A damage record can only point to an element, an asset, an owner and an event that already exist in the database. When entering new data, work in this order:

1. **Register the owner** in [Owner Profiles](data-entry/owner-profiles.md), so it can be linked to the asset.
2. **Register the asset** in [Baseline Information](data-entry/baseline/index.md) and link it to its owner.
3. **Catalogue the asset's elements** in [Elements & Production](data-entry/baseline/elements-production.md). Only elements listed here can be selected as damaged later.
4. **Register the event** in [Events](data-entry/events.md), if it is not in the database yet.
5. **Create a survey** in [Damage & Loss Assessment](assessment/index.md) that links the event and the asset.
6. **Record the damage** to each element, and any [economic losses](assessment/economic-losses.md).
7. **Consult the results** in [Queries & Reporting](analysis/index.md).

!!! tip "Reusing records"
    Owners, assets and events only need to be registered once. The same asset can be surveyed again after a later event, so you do not need to create a new asset record for each survey.
